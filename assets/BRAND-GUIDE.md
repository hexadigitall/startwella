# StartWella Brand — v7 OFFICIAL (Locked)

## The Rule — Read This First
White is primary. Two official files, two different jobs. Do NOT mix them up.

### 1. LOGO MASTER — for web / print / docs / social
File: logo-master-transparent.png
- White tile touches the edges of the image
- Transparent ONLY outside the corners
- Thin grey border is part of the logo here
- Use in: app header, website, PDF, WhatsApp, Instagram, pitch deck

### 2. MOBILE ICON — for iOS / Android home screen + store upload
File: logo-fullbleed-1024.png
- FULL-BLEED SQUARE, white to every edge
- NO drawn border, NO rounded corners in the file
- iOS + Android apply their OWN rounded mask. Uploading a pre-rounded icon = double-frame artifact.
- Use ONLY for: apple-touch-icon.png, icon-192/512.png, App Store 1024, Play Store 512
- NEVER use the rounded master for store upload. NEVER use the full-bleed square in a PDF/header.
