# StartWella Brand

## Logo
- Mark: Navy rounded square #0F2A44, Teal W #0EA47A, Gold dot #F2B705
- Meaning: W = Wella / Wealth / Win. Gold dot = profit / coin. Upward shape = growth.
- Clear space: height of gold dot on all sides. Min size: 32px digital, 16px favicon.
- Do NOT: stretch, recolour, add shadow, put on busy photo without white card.

## Colours
- Navy #0F2A44 (primary, headers)
- Teal #0EA47A (action, success)
- Gold #F2B705 (accent, profit)
- Light #EAF6F1 (result cards)
- Grey #5A6B7C (secondary text)
- Background #F2F4F7

## Typography
- Headings: System Bold / Inter Bold
- Body: System / Inter Regular
- Numbers: Tabular, always with ₦
